# PyChess

A simple **2-player local chess game** in Python. Play standard chess on the same computer with basic rules and some special moves.

## Project Structure
  ### ChessMain.py # Main file: handles input and displays the board
  ### ChessEngine.py # Game logic: valid moves, game state, special mechanics
  ### ChessImages/ # Piece and board images
  
## Features

- Two-player local game  
- Standard chess moves  
- Special moves: castling, pawn promotion
